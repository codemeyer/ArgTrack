# Tree View Menu - Computer Cars Section

This section contains data related to the computer cars.

## Racing Line Header

Double-clicking this item opens up the [racing line header](/argtrack/screens/racing-line-header-window/) window.


## Racing Line Segments

When expanded, this section displays a list of all computer car racing line segments.

<img src="/argtrack/images/racing-line-segments-treeview.png" alt="Racing line treeview screenshot" class="img-fluid img-border" />

Double-clicking on an item in the list opens it for editing with
the [racing line segment details](/argtrack/screens/racing-line-segment-details-window/) window.

If you right-click on the "Racing Line Segments" header, you get the following context menu:

- **Add New Segment:** Let's you add a new segment to the end of the list

You can right-click on an item to open a context menu containing the following options:

- **Edit:** Edits the selected segment
- **Add New Segment:** Let's you add a new segment to the end of the list
- **Insert New Segment Before:** Let's you insert a new segment _before_ the one that is selected
- **Insert New Segment After:** Let's you insert a new segment _after_ the one that is selected
- **Remove Segment:** Removes the selected segment (needs confirmation)


## Car Setup

This allows you to edit the car setup that the computer car uses in the game.

Double-clicking this item opens up the [computer car setup](/argtrack/screens/computer-car-setup-window/) window.


## Behavior

Here you can manipulate various behaviors for the computer cars, e.g. tweak how late they brake.

Double-clicking this item opens up the [computer car behavior](/argtrack/screens/computer-car-behavior-window/) settings window.
