# Top Menu

The menu at the top of the window contains the following functionality:


### File menu

<table class="table table-bordered table-striped table--medium">
    <thead>
        <tr>
            <th>Item</th>
            <th>Command</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Open</td>
            <td>Loads a track file from disk into the editor</td>
        </tr>
        <tr>
            <td>Save</td>
            <td>Saves the current track to disk</td>
        </tr>
        <tr>
            <td>Exit</td>
            <td>Exits the application</td>
        </tr>
    </tbody>
</table>

<br/>



### Data menu

<table class="table table-bordered table-striped table--medium">
    <thead>
        <tr>
            <th>Item</th>
            <th>Command</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Track Sections</td>
            <td>
                Opens the <a href="/argtrack/screens/track-section-list-window/">track sections list view window</a>
            </td>
        </tr>
        <tr>
            <td>Pit Lane Sections</td>
            <td>
                Opens the <a href="/argtrack/screens/pit-lane-section-list-window/">pit lane sections list view window</a>
            </td>
        </tr>
        <tr>
            <td>Computer Car Racing Line</td>
            <td>
                Opens the <a href="/argtrack/screens/racing-line-list-window/">computer car racing line list view window</a>
            </td>
        </tr>
        <tr>
            <td>Object Settings</td>
            <td>
                Opens the <a href="/argtrack/screens/object-settings-list-window/">object settings list view window</a>
            </td>
        </tr>
        <tr>
            <td>Object Shapes</td>
            <td>
                Opens the <a href="/argtrack/screens/object-shapes-list-window/">object shapes list view window</a>
            </td>
        </tr>
    </tbody>
</table>

<p><br/></p>


### Tools menu

<table class="table table-bordered table-striped table--medium">
    <thead>
        <tr>
            <th>Item</th>
            <th>Command</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Validate Track</td>
            <td>
                Opens the <a href="/argtrack/screens/track-validation-window/">Track Validation window</a> and displays anything that is wrong with the track
            </td>
        </tr>
        <tr>
            <td>Convert GP2 Track...</td>
            <td>
                Let's you convert (part of) a GP2 track to the F1GP format by opening
                the <a href="/argtrack/screens/gp2-track-conversion-window/">GP2 Track Conversion window</a>.
            </td>
        </tr>
    </tbody>
</table>
