# Tree View Menu - Misc Data Section

This section contains various data that does not fit under the other sections.


### World Location

Double-clicking this item opens up the [world location](/argtrack/screens/world-location-settings-window/) window.


### Car Settings

General car settings that affect both your car and the computer cars.

Double-clicking this item opens up the [general car settings](/argtrack/screens/car-settings-window/) window.
