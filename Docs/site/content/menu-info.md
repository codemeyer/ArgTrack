<h1 id="menu-info">Menu Info</h1>

<p>
    The menu at the top of the window contains the following functionality:
</p>

<h2 id="file-menu">File menu</h2>

<table class="table table-bordered table-striped table--medium">
    <thead>
        <tr>
            <th>Item</th>
            <th>Command</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Open</td>
            <td>Loads a track file from disk into the editor</td>
        </tr>
        <tr>
            <td>Save</td>
            <td>Saves the current track to disk</td>
        </tr>
        <tr>
            <td>Exit</td>
            <td>Exits the application</td>
        </tr>
    </tbody>
</table>

<h2 id="tools-menu">Tools menu</h2>

<table class="table table-bordered table-striped table--medium">
    <thead>
        <tr>
            <th>Item</th>
            <th>Command</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Validate Track</td>
            <td>
                Opens the <a href="/argtrack/track-validation-window">Track Validation window</a> and displays anything that is wrong with the track
            </td>
        </tr>
        <tr>
            <td>Convert GP2 Track...</td>
            <td>
                Let's you convert (part of) a GP2 track to the F1GP format by opening
                the <a href="/argtrack/gp2-track-conversion-window">GP2 Track Conversion window</a>.
            </td>
        </tr>
