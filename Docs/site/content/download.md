ArgTrack works on all recent versions of Microsoft Windows. For more details, have a look
at the [System Requirements](/argtrack/system-requirements) page.

Before you start editing, please make a backup of your F1GP folder!


## Installation

Unzip and place the argtrack.exe file in your F1GP/WC folder, or anywhere you like, and run it from there.

Note: If you are running Windows XP, Windows Vista or Windows 7, your installation of Windows may not
feature the Microsoft .NET Framework 4.0 that. In this case, starting the
program will display an error saying "The application failed to initialize properly." If this happens,
you should try to download and install the Microsoft .NET Framework 4.0 Client Profile, which can
be found here: 
<a href="https://www.microsoft.com/en-us/download/details.aspx?id=24872">https://www.microsoft.com/en-us/download/details.aspx?id=24872</a>


## Release notes

Below are the release notes for each released version of ArgTrack.


### 0.5.1

Released 2020-04-28 - [Download](/downloads/argtrack/ArgTrack-0.5.1.zip)

- Fix: Can load tracks with multiple track-width changes in single section
- Fix: Can load tracks with references to non-existing track-side objects



### 0.5

Released 2020-04-24 - [Download](/downloads/argtrack/ArgTrack-0.5.zip)

- Verge drawing is improved and corrected and activated by default
- Track-side objects are marked on the track with small "diamond" shapes
- Data windows for track sections and pit lane are not modal and can be open while editing other data
- Main window is larger by default, and the track is zoomed in more after loading
- Documentation expanded with new [Topics](/argtrack/topics/) section
- Fix: Left-hand corners with width changes are now drawn correctly
- Fix: Some tracks no longer have verges drawn over the entire inner area
- Fix: Keyboard shortcuts for zooming now also work properly after toggling what to draw on screen
- _Known issue: Track view occasionally ends up outside scrollable area_
- _Known issue: Some input validation missing meaning that it's possible to save broken track files_



### 0.4

Released 2020-04-17 - [Download](/downloads/argtrack/ArgTrack-0.4.zip)

- Track is redrawn after layout-affecting changes
- View stays somewhat more the same after redrawing
- Toolbar that allows toggling what is drawn (track, pit lane, verges)
- Initial drawing of track verges (disabled by default)
- Keyboard shortcuts for zooming in and out, Ctrl+ and Ctrl-
- Fix GP2 track conversion bug (now uses kerb colors from template F1GP track instead)


### 0.3

Released 2020-04-08 - [Download](/downloads/argtrack/ArgTrack-0.3.zip)

- Track layout drawn on screen so that you know what you are doing!
- [Tree view menu](/argtrack/menus/tree-view-menu/) on the left
- Ability to manipulate more [track settings](/argtrack/screens/misc-track-layout-settings-window/)
- Ability to edit [general car settings](/argtrack/screens/car-settings-window/)
- Ability to edit [computer car behavior](/argtrack/screens/computer-car-behavior-window/)
- Ability to edit [track cameras](/argtrack/screens/camera-list-window/)
- Restructured, extended and improved documentation - press F1 on any screen for help


### 0.2

Released 2018-08-24 - [Download](/downloads/argtrack/ArgTrack-0.2.zip)

- Initial [GP2 track conversion](/argtrack/screens/gp2-track-conversion-window/) (track and pit lane sections only)
- Initial [track validation](/argtrack/screens/track-validation-window/)
- Can rearrange track sections, pit lane sections and best line segments
- Can insert track sections, pit lane sections and best line segments among others, not just at the end
- More/better track command and argument descriptions
- Much more detailed documentation
