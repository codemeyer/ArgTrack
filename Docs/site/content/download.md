ArgTrack works on all recent versions of Microsoft Windows. For more details, have a look
at the [System Requirements](/argtrack/system-requirements) page.

Before you start editing, please make a backup of your F1GP folder!


## Installation

Unzip and place the argtrack.exe file in your F1GP/WC folder, or anywhere you like, and run it from there.

Note: If you are running Windows XP, Windows Vista or Windows 7, your installation of Windows may not
feature the Microsoft .NET Framework 4.0 that. In this case, starting the
program will display an error saying "The application failed to initialize properly." If this happens,
you should try to download and install the Microsoft .NET Framework 4.0 Client Profile, which can
be found here: 
<a href="https://www.microsoft.com/en-us/download/details.aspx?id=24872">https://www.microsoft.com/en-us/download/details.aspx?id=24872</a>


## Release notes

Below are the release notes for each released version of ArgTrack.


### 0.3

Released 2020-04-08 - [Download](/downloads/argtrack/ArgTrack-0.3.zip)

- Track layout drawn on screen so that you know what you are doing!
- [Tree view menu](/argtrack/menus/tree-view-menu/) on the left
- Ability to manipulate more [track settings](/argtrack/screens/misc-track-layout-settings-window/)
- Ability to edit [general car settings](/argtrack/screens/car-settings-window/)
- Ability to edit [computer car behavior](/argtrack/screens/computer-car-behavior-window/)
- Ability to edit [track cameras](/argtrack/screens/camera-list-window/)
- Restructured, extended and improved documentation - press F1 on any screen for help
- _Known issue: Track view occasionally ends up outside scrollable area_
- _Known issue: Track view not always redrawn after editing layout-affecting properties_
- _Known issue: Left-hand corner with width change is drawn incorrectly_
- _Known issue: Some input validation missing meaning that it's possible to save broken track files_
