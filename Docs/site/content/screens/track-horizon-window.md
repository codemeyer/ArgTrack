# Track Horizon window

Here you can see the horizon that the game renders for the track. You can load a horizon (e.g. from another track file) or save it to disk.

<img src="/argtrack/images/track-horizon-window.png" alt="Track horizon window screenshot" class="img-fluid" />

The 1x view is a pixel-per-pixel representation, whilst the 8x is magnified so that it's easier to see on modern screens.

The "Load Horizon" button lets you load a horizon from any type of file.

The "Save Horizon" button lets you save the current horizon to disk as a .arghoriz file.
