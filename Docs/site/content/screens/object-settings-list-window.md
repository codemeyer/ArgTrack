# Object Settings List window

Displays a list of all object settings defined in the track.

<img src="/argtrack/images/object-settings-list-window.png" alt="Object shapes window screenshot" class="img-fluid" />

Double-click an item to edit it using
the [object settings details](/argtrack/screens/object-settings-details-window/) window.
