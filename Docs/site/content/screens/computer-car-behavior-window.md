# Computer Car Behavior window

Allows you to edit the computer car behavior.

<img src="/argtrack/images/computer-car-behavior-window.png" alt="Computer car behavior window screenshot" class="img-fluid" />

The following properties can be edited:

<table class="table table-bordered table-striped ">
<thead>
  <tr>
    <th>Name</th>
    <th>Description</th>
  </tr>
</thead>
<tbody>
  <tr>
    <td>Late Braking Factor Non-Race</td>
    <td>Affects how late the computer cars brake in non-race sessions.</td>
  </tr>
  <tr>
    <td>Late Braking Factor Race</td>
    <td>Affects how late the computer cars brake in non-race sessions.</td>
  </tr>
  <tr>
    <td>Late Braking Factor Wet Race</td>
    <td>Affects how late the computer cars brake in non-race sessions.</td>
  </tr>
  <tr>
    <td>Formation Length</td>
    <td>
        Length (in track units) that computer cars will avoid steering left or right
        at the start of a race.
</td>
  </tr>
  <tr>
    <td>Power Factor</td>
    <td>Computer car power factor.</td>
  </tr>
  <tr>
    <td>Strategy First Pit Stop Lap</td>
    <td>The first lap that cars will start to pit (100% race).</td>
  </tr>
  <tr>
    <td>Strategy Chance</td>
    <td>Chance that the strategy above is applied.</td>
  </tr>
</tbody>
</table>
