# World Location Settings window

Let's you edit various world-location related properties, as well as some that don't quite fit anywhere else
at the moment.

<img src="/argtrack/images/world-location-window.png" alt="World location window screenshot" class="img-fluid" />

The following properties can be edited:

<table class="table table-bordered table-striped table--medium">
    <thead>
        <tr>
            <th>Name</th>
            <th>Description</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>First Section Angle</td>
            <td>Angle of the first section</td>
        </tr>
        <tr>
            <td>First Section Height</td>
            <td>Height change for the first section(?)</td>
        </tr>
        <tr>
            <td>Track Start Width</td>
            <td>Width of the track where the track starts</td>
        </tr>
        <tr>
            <td>Left Verge Start Width</td>
            <td>The width of the left track verge where the track begins</td>
        </tr>
        <tr>
            <td>Right Verge Start Width</td>
            <td>The width of the right track verge where the track begins</td>
        </tr>
        <tr>
            <td>Track Center X</td>
            <td>Coordinate for the track center location in the 3D world</td>
        </tr>
        <tr>
            <td>Track Center Y</td>
            <td>Coordinate for the track center location in the 3D world</td>
        </tr>
        <tr>
            <td>Track Center Z</td>
            <td>Coordinate for the track center location in the 3D world</td>
        </tr>
    </tbody>
</table>
