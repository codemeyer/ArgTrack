# Object Shapes List window

Displays a list of all object shapes defined in the track.

<img src="/argtrack/images/object-shapes-list-window.png" alt="Object shapes window screenshot" class="img-fluid" />

Double-click an item to edit it using
the [object shape details](/argtrack/screens/object-shape-details-window/) window.
