# Pit Lane Section List window

This window displays a list of all the pit lane sections of the track.

<img src="/argtrack/images/pit-lane-section-list-window.png" alt="Pit lane section list window screenshot" class="img-fluid" />

You can double-click a pit lane section to edit it, or use the menu at the top to add, insert or remove items.

It is also possible to rearrange the sections using the two buttons with arrows.
