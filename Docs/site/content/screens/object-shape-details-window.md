<h1 id="object-shape-details-window">Object Shape Details Window</h1>

<p>
    This window allows you to perform some very rough editing
    of a 3D object.
</p>

<img alt="Object shape details window screenshot" src="/argtrack/images/argtrack-object-shape-details.png" class="img-fluid" />

<p>
    All of the values <em>can</em> be edited, but probably not all of them <em>should</em> be edited.
</p>

<p>
    By clicking on the "Edit" button that appears next to some of the entries,
    a new window is opened that allows you to edit the individual byte values.
</p>
