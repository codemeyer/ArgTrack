# Track Layout Misc Settings

This window allows you to edit various track related settings.

<img src="/argtrack/images/track-layout-misc-settings.png" alt="Track Layout Misc Settings screenshot" class="img-fluid" />

The data that can be edited now is:

<table class="table table-bordered table-striped table--medium">
    <thead>
        <tr>
            <th>Name</th>
            <th>Description</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Lap Count</td>
            <td>The number of laps in a 100% race</td>
        </tr>
        <tr>
            <td>Surrounding Area</td>
            <td>Whether the area surrounding the track is green (grass) or gray</td>
        </tr>
        <tr>
            <td>Pole Side</td>
            <td>Which side of the track that pole position is on, left or right</td>
        </tr>
        <tr>
            <td>Pits Side</td>
            <td>Which side of the track that the pits are located</td>
        </tr>
        <tr>
            <td>Kerb Type</td>
            <td>Whether kerbs have two or three colors (one of which is always white)</td>
        </tr>
        <tr>
            <td>Kerb Fixed Upper Color</td>
            <td>Upper color of kerbs that cannot be changed</td>
        </tr>
        <tr>
            <td>Kerb Fixed Lower Color</td>
            <td>Lower color of kerbs that cannot be changed</td>
        </tr>
        <!-- color 2 -->
        <tr>
            <td>Lap Time Indication</td>
            <td>
                An indication of lap time (in milliseconds) that is used to determine
                the duration of hot-seat stints, as well as the number of simultaneous
                runners during a non-race sessions.
            </td>
        </tr>
        <tr>
            <td>Time Factor Non-Race</td>
            <td>Time factor in sessions that are not race sessions</td>
        </tr>
        <tr>
            <td>Time Factor Race</td>
            <td>Time factor in a race session</td>
        </tr>
        <tr>
            <td>Pit Lane Default Draw Distance</td>
            <td>Default pit lane view distance</td>
        </tr>
        <tr>
            <td>Unknown Track Distance</td>
            <td>Unknown track distance-related value</td>
        </tr>
    </tbody>
</table>
