# Track Section List window

This window displays a list of all track sections that make up the track.

<img src="/argtrack/images/track-section-list-window.png" alt="Track Section list window screenshot" class="img-fluid" />

You can double-click a track section to edit it, or use the menu at the top to add, insert or remove items.

It is also possible to rearrange the sections using the two buttons with arrows.
