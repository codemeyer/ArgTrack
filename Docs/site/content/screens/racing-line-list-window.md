# Computer Car Racing Line List window

This window displays a list of all computer car racing line segments that make up the track.

<img src="/argtrack/images/computer-car-racing-line-list-window.png" alt="Computer car racing line segment list window screenshot" class="img-fluid" />

You can double-click a segment to edit it, or use the menu at the top to add, insert or remove items.

It is also possible to rearrange the segments using the two buttons with arrows.
