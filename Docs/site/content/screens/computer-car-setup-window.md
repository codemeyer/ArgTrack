# Computer Car Setup window

The computer car setup window allows you to edit the car setup that
the computer cars use.

<img src="/argtrack/images/computer-car-setup.png" alt="Computer car setup window screenshot" class="img-fluid" />

Note: The default behavior in F1GP is that the game will ignore the front wing setting, and use the
rear wing setting for both values. The value will also be randomized slightly up or down.
