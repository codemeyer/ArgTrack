# Keyboard Shortcuts

There are various keyboard shortcuts available based on which part of the
user interface you are currently viewing.


<table class="table table-bordered table-striped table--small">
    <thead>
        <tr>
            <th>Shortcut</th>
            <th>Command</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>F1</td>
            <td>Opens web browser to show help/documentation</td>
        </tr>
        <tr>
            <td>Ctrl + O</td>
            <td>Load a track from disk</td>
        </tr>
        <tr>
            <td>Ctrl + S</td>
            <td>Save track to disk</td>
        </tr>
        <tr>
            <td>Ctrl + +</td>
            <td>Zoom in on track view</td>
        </tr>
        <tr>
            <td>Ctrl + -</td>
            <td>Zoom out on track view</td>
        </tr>
    </tbody>
</table>
